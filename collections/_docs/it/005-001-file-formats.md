Ink/Stitch supporta molti formati di ricamo. Può importare ed esportare file nei formati elencati di seguito.

## Formati di File di Ricamo Supportati (A - Z):

### Scrittura

#### Ricamo

**DST**, **EXP**, G-CODE, **JEF**, PEC, **PES**, TBF, U01, **VP3**, XXX

#### Colore

COL, EDR, INF

#### Formati di Punto

PMV

#### Quilting

PLT, QCC

#### Formati Utilità

CSV, JSON, PNG, TXT, SVG

### Lettura

#### Ricamo

100, 10o, BRO, DAT, DSB, **DST**, DSZ, EMD, **EXP**, EXY, FXY, G-CODE, GT, HUS, INB, **JEF**, JPX, KSM, MAX, MIT, NEW, PCD, PCM, PCQ, PCS, PEC, **PES**, PHB, PHC, SEW, SHV, SPX, STC, STX, TAP, TBF, U01, **VP3**, XXX, ZHS, ZXY

#### Colore

COL, EDR, INF

#### Formati di Punto

PMV

#### Quilting

IQP, PLT, QCC

#### Formati Utilità

CSV, JSON

**Informazioni:** Informazioni dettagliate sui formati di file di ricamo sono disponibili su [EduTechWiki](http://edutechwiki.unige.ch/en/Embroidery_format).

Inoltre, è possibile esportare una vista PDF dettagliata del proprio disegno o creare un elenco di fili in formato txt.
