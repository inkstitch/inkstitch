Segui i seguenti passaggi per apprendere le funzionalità di base di Ink/Stitch.

**Suggerimento:** Se sei nuovo su Inkscape, potresti voler consultare il [Tutorial Base di Inkscape](https://inkscape.org/en/doc/tutorials/basic/tutorial-basic.html) prima di iniziare.
{: .notice--info }

## Passo 1 - Disegna un Oggetto

1. Crea un oggetto, ad esempio un cerchio, e verifica che abbia un colore di riempimento.
2. Se non sai come creare un oggetto o cosa significa "riempimento", consulta il [Tutorial Base di Inkscape](https://inkscape.org/en/doc/tutorials/basic/tutorial-basic.html).

![Cerchio con colore di riempimento](/assets/images/docs/en/basic-usage-circle-fill-color.png)

## Passo 2 - Parametrizzazione del Percorso SVG per la Ricamatura

1. Seleziona l'oggetto.
2. Apri `Estensioni > Ink/Stitch > Parametri`. Questo avvierà l'estensione in un'altra finestra.
3. Regola i valori. Il simulatore aggiorna l'anteprima quando modifichi le impostazioni.
4. Chiudi la finestra senza salvare.

**Nota:** Se non vedi una scheda nella parte superiore della finestra di Ink/Stitch denominata `FillStitch`, significa che non hai selezionato un oggetto che ha un riempimento oppure non hai selezionato un oggetto che è un percorso. Dovrai convertire il tuo oggetto in un percorso.
{: .notice--info}

## Passo 3 - Crea il file di ricamatura

1. Dal menu di Inkscape, seleziona `File > Salva una copia...`
2. Vai alla cartella in cui desideri salvare il file.
3. Scegli il formato di file corretto per la tua macchina.
4. Seleziona `Salva una copia`. Ora puoi copiare il file nella tua macchina per utilizzarlo.

**Suggerimento:** Salva il file come SVG in modo da poterlo modificare in seguito.
{: .notice--info}

## Workflow

Se i passaggi precedenti hanno funzionato correttamente, continua alla pagina successiva relativa al Flusso di Lavoro. Questa pagina offre un'analisi più approfondita di Ink/Stitch e spiega come eseguire attività importanti per la preparazione dei file di ricamatura, come l'ordinamento degli oggetti e la gestione delle sequenze di punti.

Se riscontri problemi, puoi contattarci tramite [GitHub](https://github.com/inkstitch/inkstitch/issues/). Accogliamo i segnalazioni di problemi perché ci aiutano a migliorare la documentazione e Ink/Stitch.
