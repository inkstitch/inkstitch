Ink/Stitch può applicare threadlist personalizzate a un disegno di ricamo. Questo è particolarmente utile se si desidera lavorare su file di ricamo esistenti che non supportano le informazioni sui colori (ad esempio, DST).

Potrebbe essere utile anche se si desidera testare diverse impostazioni di colore. È possibile esportarle e importarle a piacimento. Tuttavia, fare attenzione a non modificare il numero e l'ordine dei colori. Se si prevede di modificare questi elementi, è preferibile salvare l'intero file SVG.

## Applicazione dei colori di una colorlist (threadlist) a un disegno
Eseguire `Estensioni > Ink/Stitch > Gestione dei colori dei fili > Applica threadlist...` per applicare una threadlist esportata da Ink/Stitch.

Se si desidera applicare un'altra threadlist da un file txt, scegliere l'opzione "Applica altra threadlist" e selezionare una threadlist dal menu a tendina prima di fare clic su "applica".

**Suggerimento:** Eseguire `Estensioni > Ink/Stitch > Gestione dei colori dei fili > Installa palette di colori per Inkscape` per avere a disposizione più palette di colori.
{: .notice--info }

## Esportazione

Le threadlist possono essere esportate solo tramite un file zip ([esportazione batch](/docs/import-export/#batch-export)).
