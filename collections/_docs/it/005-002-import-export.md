## Importazione di File di Ricamo

Apri un file di ricamo come apriresti qualsiasi file SVG in Inkscape: `File > Apri...` > scegli il tuo file e fai clic su `Apri`.

Il file si aprirà in [Modalità Cucitura Manuale](/docs/stitches/manual-stitch/). Puoi modificare i singoli punti e perfezionare il tuo design. Una volta soddisfatto, salva il file come descritto di seguito.

## Esportazione di File di Ricamo

Esporta i file direttamente tramite la finestra `File > Salva una copia...` (`Ctrl + Shift + Alt + S`) di Inkscape.

Seleziona un formato di file che la tua macchina da ricamo può leggere e `Salva` il file nella cartella di output desiderata.

![Campo Formato File](/assets/images/docs/en/export-selection-field.jpg)

Per modifiche successive, assicurati di conservare anche una versione SVG del tuo design.

## Esportazione Batch

Vai su `File > Salva una copia...` e fai clic sulla piccola freccia nel campo di selezione del formato file per aprire un elenco dei formati di file disponibili.

Naviga nella cartella di output desiderata e scegli il formato file Ink/Stitch ZIP. Fai clic su `Salva`. Ti verrà quindi chiesto quali formati di file desideri includere.

![Esportazione batch](/assets/images/docs/en/export-batch.jpg)

Se desideri che i file all'interno dell'archivio ZIP abbiano un nome diverso dal file SVG originale precedentemente salvato, inserisci il nome del file nel campo "nome file personalizzato".

![Opzioni di esportazione batch](/assets/images/docs/en/zip-export1.png)

L'esportazione ZIP offre anche opzioni di pannellatura. Se i valori di ripetizione sono superiori a uno, Ink/Stitch creerà copie del piano di cucitura e le posizionerà a distanze definite.
Le distanze sono misurate dalla posizione in alto a sinistra del design originale. I blocchi di colore verranno ordinati per ridurre i cambi di colore.
