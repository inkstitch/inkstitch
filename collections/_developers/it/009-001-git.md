## Crea un Nuovo Branch e Carica le Modifiche con Git

* **Clona il repository**

  Per una configurazione manuale completa, consulta le istruzioni per il tuo sistema operativo: [Linux/macOS](/developers/inkstitch/manual-setup/), [Windows](/developers/inkstitch/windows-manual-build/)

  ```
  git clone https://github.com/inkstitch/inkstitch.git
  cd inkstitch
  ```

* **Crea ed entra in un nuovo branch** (anche se hai già apportato modifiche)

  ```
  git checkout -b username/branch-name
  ```

* **Visualizza i file modificati o il nome del branch corrente**

  ```
  git status
  ```

* **Visualizza le modifiche**

  ```
  git diff
  ```

* **Aggiungi le modifiche all'area di staging**

  ```
  git add *
  ```

  Oppure, aggiungi solo file specifici:

  ```
  git add path-to-filename.ext
  ```

* **Salva le modifiche (commit)**

  ```
  git commit -m 'messaggio del commit'
  ```

* **Carica le modifiche in un nuovo branch nel repository principale**

  ```
  git push -u origin username/branch-name
  ```

  **Carica le modifiche in un branch esistente nel repository principale** (dopo aver utilizzato `git add` e `git commit`)

  ```
  git push
  ```

* **Torna al branch principale**

  ```
  git checkout main
  ```

  o qualsiasi altro branch

  ```
  git checkout username/branch-name
  ```

  Se vuoi lavorare sul **sito web**, utilizza il branch `gh-pages`:

  ```
  git checkout gh-pages
  ```

Ink/Stitch costruirà ora una versione di sviluppo, che può essere trovata in <https://github.com/inkstitch/inkstitch/releases> (in circa 25 minuti).

Quando sei soddisfatto dei risultati, crea una pull request (vedi sopra).

## Aggiorna la Copia Locale di Ink/Stitch con le Modifiche dal Repository Principale

Per aggiornare la copia locale, utilizza semplicemente:

```
git pull
```

Questo caricherà le modifiche dal repository principale per il branch attualmente utilizzato.
