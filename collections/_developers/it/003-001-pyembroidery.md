[Pyembroidery](https://github.com/inkstitch/pyembroidery) è una libreria Python per la lettura e la scrittura di file di ricamo.

Seguite il link qui sopra. Il file README contiene molte informazioni su come può essere utilizzato e su come funziona.

## Contesto

Ink/Stitch è iniziato utilizzando [libembroidery](https://github.com/Embroidermodder/Embroidermodder/tree/master/libembroidery), sviluppato dal team di Embroidermodder.

Successivamente, @tartarize ha fornito una conversione in Python (pyembroidery) per renderlo ancora più utile per Ink/Stitch (o qualsiasi altro progetto di ricamo basato su Python).

La versione di pyembroidery utilizzata dall'organizzazione Ink/Stitch è un fork del [suo lavoro](https://github.com/EmbroidePy/pyembroidery).

## Formati di file di ricamo

La [EduTech wiki](http://edutechwiki.unige.ch/en/Machine_embroidery) è una risorsa utile per i concetti di ricamo.

È inoltre possibile trovare informazioni molto dettagliate sui [formati di file di ricamo](http://edutechwiki.unige.ch/en/Embroidery_format).
